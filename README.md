# Vault — Сервис управления пользователями и OAuth-клиентами (Костяк системы)

**Vault** — это прототип backend-сервиса аутентификации и контроля доступа, разрабатываемый в рамках Лабораторной работы №2. Проект представляет собой первый этап построения полноценного OAuth2/OIDC провайдера. В текущей версии реализован базовый контур: строгая аутентификация, GraphQL API на базе schema-first подхода, ведение сквозного бизнес-аудита безопасности и минималистичная панель администратора.

## 🛠 Технологический стек

* **FastAPI** (v0.115.0) — асинхронный веб-фреймворк для реализации REST и монтирования GraphQL.
* **Ariadne** (v0.23.0) — Schema-First GraphQL-фреймворк для Python (описание схемы на языке SDL).
* **SQLAlchemy 2.x** (v2.0.35) — ORM с использованием современного аннотированного стиля (`Mapped`).
* **Alembic** (v1.13.3) — инструмент для управления миграциями базы данных.
* **Argon2id** (`argon2-cffi`) — современный алгоритм хэширования паролей, устойчивый к GPU-атакам.
* **zxcvbn** — алгоритмическая оценка стойкости паролей на основе паттернов и словарей.
* **python-jose** — генерация и валидация JWT-токенов (алгоритм подписи HS256).
* **Pydantic Settings 2.x** — безопасное конфигурирование приложения через переменные окружения.
* **SQLite** — база данных по умолчанию для локальной разработки.

## ⚙️ Установка и настройка

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd lab2_vault
```

### 2. Настройка виртуального окружения
Создайте и активируйте виртуальное окружение:
```bash
# Для Linux / macOS
python3 -m venv venv
source venv/bin/activate

# Для Windows
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Конфигурация переменных окружения
Скопируйте пример файла конфигурации и заполните его собственными секретами. 

```bash
cp .env.example .env
```

> ⚠️ **Важно:** Файлы конфигурации `.env` и файлы баз данных `*.db` внесены в `.gitignore` и **никогда не должны попадать в удаленный репозиторий GitHub**.

Пример содержимого файла `.env`:
```ini
DATABASE_URL=sqlite:///./vault.db
JWT_SECRET=super_secret_long_random_string_for_signing_jwt
JWT_ALGORITHM=HS256
ACCESS_TOKEN_TTL_MIN=60
PASSWORD_PEPPER=global_secret_pepper_string_stored_separately_from_db
PASSWORD_MIN_LENGTH=12
ENVIRONMENT=development
APP_NAME=Vault
```

## 🚀 Запуск приложения

### 1. Применение миграций базы данных
Создайте таблицы в локальной базе данных SQLite, применив миграции Alembic до актуального состояния `head`:
```bash
alembic upgrade head
```

### 2. Старт сервера разработки
Запустите ASGI-сервер с помощью `run.py` (или напрямую через uvicorn):
```bash
python run.py
```
Сервер запустится по адресу: **`http://localhost:8000`**

### Available Endpoints:
* **`http://localhost:8000/auth/*`** — REST-эндпоинты аутентификации.
* **`http://localhost:8000/graphql`** — Интерактивная среда выполнения GraphQL-запросов (GraphQL Playground).
* **`http://localhost:8000/admin`** — Веб-интерфейс панели администратора.

## 🔒 Безопасность и Бизнес-аудит

1. **Защита паролей**: Применяется связка `Argon2id` + уникальная соль + глобальный `PASSWORD_PEPPER` из `.env`. Пароль проверяется утилитой `zxcvbn`, отсекающей любые комбинации со скором ниже 3/4.
2. **Аудит**: Любые критические действия (успешный вход, ошибка авторизации, блокировка пользователя, создание OAuth-клиента) атомарно логируются в таблицу `audit_events`. Секреты (пароли, токены) в метаданные аудита не попадают.
3. **Декларативный доступ**: GraphQL-поля защищены кастомными директивами схемы `@isAuthenticated` и `@isAdmin`.

## 📊 Примеры GraphQL-запросов

Вы можете протестировать выполнение запросов в GraphQL Playground. Для защищенных запросов необходимо передать HTTP-заголовок: `Authorization: Bearer <ваш_token>`.

### 1. Получение информации о себе (Защищенный запрос)
**Запрос:**
```graphql
query GetMe {
  me {
    id
    email
    isActive
    isAdmin
    createdAt
  }
}
```
**Ожидаемый успешный ответ:**
```json
{
  "data": {
    "me": {
      "id": 1,
      "email": "admin@vault.local",
      "isActive": true,
      "isAdmin": true,
      "createdAt": "2026-10-26T20:30:00"
    }
  }
}
```

### 2. Создание нового OAuth-клиента (Только для Администратора)
**Запрос:**
```graphql
mutation NewClient {
  createClient(name: "Mobile Dashboard App", isConfidential: true) {
    id
    clientId
    name
    isConfidential
  }
}
```
